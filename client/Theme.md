# PRD — Rise in Life Color Palette


## 1. Objective

Implement a consistent color theme across the Rise in Life application, inspired by the official logo.

**Main application background must always remain pure white (`#FFFFFF`).**

## 2. Official Color Palette

| Element | Color | HEX |
|---|---|---|
| Primary Brand | Royal Blue | `#002070` |
| Primary Hover | Deep Blue | `#00358F` |
| Secondary Brand | Electric Cyan | `#00D8F0` |
| Accent | Purple | `#8B24D6` |
| Main Background | White | `#FFFFFF` |
| Card Background | Soft Blue-White | `#F4F8FC` |
| Light Surface | Light Blue | `#E8F4FA` |
| Selected Option | Pale Cyan | `#E0F7FC` |
| Main Headings | Navy | `#172554` |
| Body Text | Slate | `#334155` |
| Secondary Text | Gray | `#64748B` |
| Placeholder | Light Gray | `#94A3B8` |
| Borders | Light Gray-Blue | `#DCE5EF` |
| Input Focus | Cyan | `#00BFEA` |
| Success | Green | `#16A34A` |
| Error | Red | `#DC2626` |

## 3. Component Color Usage

- **Patient Form:** White background, navy headings, slate labels, white inputs and cyan focus borders.
- **Questions Page:** Navy question text, soft blue option cards and cyan selected-option borders.
- **Result Page:** White background, navy headings, soft blue result cards and slate body text.
- **Primary Buttons:** Royal blue background with white text.
- **Secondary Buttons:** White background with royal blue border and text.
- **Accent Buttons:** Cyan background with navy text.

## 4. Color Distribution

- 70% White
- 20% Royal Blue / Navy
- 8% Cyan / Light Blue
- 2% Purple

## 5. Implementation Rules

1. Use the exact HEX colors specified in this document.
2. Apply the palette consistently across the entire frontend.
3. Keep the main application background pure white.
4. Use purple sparingly for decorative accents.
5. Maintain readable text contrast.
6. Do not introduce additional brand colors without approval.
7. Do not modify PDF styling or existing application functionality.

**Final Requirement:** This document defines the official frontend color palette for Rise in Life. All application pages and reusable components must follow this specification.
